# silmaril

Compile-time reactivity for JS.

`$$` defines a reactive boundary. Variables declared inside it are reactive, and `$` reacts when they change.

## Features

- Compile-time reactivity
- Minimal reactive runtime
- Auto-memoization
- Stores
